# QRA-Talk relationship and reputation evidence

QRA-Config is a Windows companion developed for QRA-Talk by the same maintainer. QRA-Talk is a separate proprietary Android project; its source code, APKs, private Git history and server integration are not included in this GPL-3.0-only source export. QRA-Config communicates through the user-authorized `qra-frn-settings` configuration protocol over local USB ADB.

## Public evidence status

The QRA-Team [network website](https://qra-team.online/) is publicly readable and describes the radio network. It is a contextual reference, not proof of QRA-Config authorship, application adoption or an established QRA-Talk release history. No download/user counts are claimed.

Before application submission the owner must provide a public QRA-Talk landing/download/documentation page that identifies the maintainer and links to the QRA-Config repository. QRA-Config must link back. An announcement on a parent-controlled public channel can reinforce the relationship. Private cabinet pages and private correspondence are not public reputation evidence.

The public source repository is `https://github.com/krot4u/QRA_Config`; its `main` workflow has completed successfully and release `v1.0.0` is public. This establishes a public source and release location, but does not by itself demonstrate the reciprocal QRA-Talk relationship or sufficient reputation. Foundation decides whether the submitted evidence is sufficient.
